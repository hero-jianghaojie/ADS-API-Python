# 方法：以 EM 仿真为判据的多边形级版图优化

本文描述的是一套完整的优化闭环，只需要三样东西：可由命令行驱动的 EM 求解器、
把版图当作多边形来编辑的能力、以及固定的评估口径。本文与具体软件无关；
`src/emlayout` 实现了其中最容易做错的那几块。

## 1. 先选表示形式

| 路线 | 适用 | 失效场景 |
| --- | --- | --- |
| 改生成器参数、重新生成版图 | 版图完全由原理图生成，且生成器可信 | 版图是手工调过的；或生成出来的图形与实测那一版不同 |
| 直接编辑多边形 | 总是可行，且保持现有版图不变 | 需要连通性闸门，因为改一条边就可能开口 |

手工调过的板子通常属于第二行：重新生成会挪动所有顶点，测出的响应变化与你研究的旋钮无关。
编辑多边形能保持对照干净，代价是要做连通性记账（第 3 节）。

## 2. 动手之前先定义“量尺”

所有候选必须用同一把尺子评分，并且把口径写下来，之后不许悄悄改：

```
频带        1.6 - 2.6 GHz，步长 0.05 GHz
驱动        Pin = 30 dBm，固定
偏置        固定直流，记录在案
谐波阶数    5，过采样 >= 2 倍阶数
端接        其余端口 50 欧
输出        效率、输出功率、直流功耗，全部落盘
```

其中两条最贵：

- **分辨率**：0.1 GHz 网格可能直接跨过一个比 0.1 GHz 还窄的陷波。本项目里，0.1 GHz 给出 58.2%，
  而 0.05 GHz 在 50 MHz 之外发现 53.2%。
- **谐波阶数**：阶数截断太早会低估压缩器件的整流直流分量，使效率系统性偏低约 0.5-1 个点。
  阶数与过采样倍数是口径的一部分，不是细节。

## 3. 每次编辑都过闸门

一次多边形编辑只有在以下三条全部成立时才允许送仿真：

1. **确实改了东西**（选择器至少命中一个多边形，且落盘文件与基准文件不同）；
2. **岛数不变**——在阶梯链上只改一段的宽度，会在台阶处开口，求解器要么报开路，要么直接拒绝；
3. **每个端口仍在金属上，且仍属于原来的岛**。

## 4. 用灵敏度挑旋钮，而不是靠直觉

| 旋钮类别 | 典型效应 | 原因 |
| --- | --- | --- |
| RF 通路上的开路支节 | **大** | 它移动一个谐振点，而谐振可以有几 dB 深 |
| 级联 RF 链路里的长度 | 中 | 改变整段下游的电长度（相位） |
| 偏置/检测支路上的支节 | 约等于零 | 支路末端是 50 欧端接的端口，根本不给 RF 通路加载 |

实用的筛选办法：每一类挑一个代表，改 0.5 mm，只保留“改变量大于重复性误差”的类别。

## 5. 移动谐振，不要“躲”谐振

如果某个坑来自支节，它的位置与深度由支节长度决定：

```
支节 3.2 mm  ->  坑在 2.15 GHz，53.5%
支节 3.8 mm  ->  坑移出带内，带内最小变为 58.4%
支节 4.4 mm  ->  坑在 2.10 GHz 重新出现，且更深
```

由此有两个陷阱。第一，细网格如果正好跨在坑的两侧，会报出比真实更好的最小值——必须声明网格。
第二，如果版图里没有有耗元件，唯一真正消除坑的办法是把谐振推出频带，而这往往会在别处长出新的坑。

## 6. 记录、画图、再决策

每个候选保留：被仿真的多边形文件、求解器输出、以及一份指标 JSON
（`{name: [[f_GHz, pout_dBm, eff_pct], ...]}`）。

图一律从 JSON 重画，不重跑仿真，所以换坐标轴、加目标线只需几秒。决策基于整条曲线，而不是最优点。

## 7. 什么时候停

停的判据：剩余差距小于口径本身的不确定度（网格分辨率、网格划分、谐波阶数）。
为了最后零点几个点继续拧几何，通常会得到无法制造的版图——本项目里，耦合缝动 0.01 mm 就要付 7.6 个点，
这使制造公差比优化步长还要紧。
