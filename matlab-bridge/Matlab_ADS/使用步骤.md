# MATLAB-ADS 联合仿真 · 快速上手

> 环境：MATLAB R2025a + ADS 2025 Update 2　|　工具目录：`d:\AppGallery\codex\Matlab_ADS`
> 详细原理见 `README.md`；本文只讲怎么跑通。

---

## 1. 三步跑通

### ① 启动 MATLAB

⚠️ 别在**激活了 venv 的终端**里启动（会选错 Python 3.10）。

```powershell
cd d:\AppGallery\codex\Matlab_ADS
& "D:\Program Files\MATLAB\R2025a\bin\matlab.exe" -batch "test_e2e_ads"
```

GUI 方式：先 `cd('d:\AppGallery\codex\Matlab_ADS')`，否则报 `函数或变量 'ads_init' 无法识别`。

### ② 初始化桥接

```matlab
[de, ds] = ads_init();      % 自动：切 Python(OutOfProcess) + 设 HPEESOF_DIR + 导入模块
```

### ③ 四段式用法

```matlab
ws  = de.open_workspace('D:\AppGallery\codex\ADS\python_wrk');      % 1 打开工作区
d   = ws.design('python_lib:py_ms_lpf:schematic');                  % 2 打开设计
nl  = d.generate_netlist();                                          % 3 生成网表
out = read_ads_dataset('D:\AppGallery\codex\ADS\python_wrk\data\py_ms_lpf.ds'); % 4 读数据

% 之后全是纯 MATLAB 处理：
plot(out.freq_ghz, 20*log10(abs(out.S.S_2_1))); grid on;
```

## 3. 三个必知坑

1. **必须 OutOfProcess**：`ads_init` 已处理；手动配置为 `pyenv('Version', ADS_PY, 'ExecutionMode','OutOfProcess')`，否则报 `Failed to load the _pde extension module`。
2. **HPEESOF_DIR 要在 import 前设**：`ads_init` 已处理。
3. **.m 里别写 `obj.__xxx__`**：会报"文本字符无效"；取列用 `df.get('S[2,1]')`、转字符用 `char(obj)`。

## 5. 常见报错速查

| 报错 | 处理 |
|---|---|
| `函数或变量 'ads_init' 无法识别` | 先 `cd('d:\AppGallery\codex\Matlab_ADS')` 或 `addpath(...)` |
| `No module named 'keysight'` | 别在 venv 终端启动；确认 `pyenv` 显示 3.12 |
| `Failed to load the _pde extension module` | 用 OutOfProcess |
| `HPEESOF_DIR must be set` | import 前 `setenv('HPEESOF_DIR', ...)` |
| `vtb.defs ... Cannot read` 警告 | 忽略，非错误 |
| `hpeesofsim ... 0xC0000135 / DLL 找不到` | 需 ADS 全部组件子目录在 PATH（已封装进 `ads_sim_helper.py`） |

## 6. 进阶：自动优化闭环（可选）

已打通「MATLAB 自动设参 → 仿真 → 读回 → 迭代」闭环，可直接跑示例：

```powershell
& "D:\Program Files\MATLAB\R2025a\bin\matlab.exe" -batch "demo_optimize"
```

`demo_optimize.m` 用 `fminsearch` 优化 LPF 截止频率到 2.0 GHz（改 TL2/TL4/TL6 长度），
每轮：`ads_set_param`（设参）→ `ads_run_sim`（跑 hpeesofsim+读回）→ `ads_lpf_cost`（代价）。
实测：截止频率 `1.892 → 1.998 GHz`，生成 `optimize_result.png`。
