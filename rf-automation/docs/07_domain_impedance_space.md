# 07 领域约定与阻抗空间（PA/匹配优化的"业务口径"）

## 1. 用户硬性偏好（**不要违背**）
- **布局单位 = 毫米(mm)**；新建 ADS 库用 `lib.create_layout_tech_std_ads("mm", 1000)`；已有库改单位只能在 GUI 的 Technology Setup→Layout Units 改（程序化改会报 tech graph 冲突）。
- **库/单元/视图/网络/端口/变量/数据集名一律英文 ASCII**（小写+下划线）；工作区**路径也要全 ASCII**（中文会让 hpeesofsim/Momentum 生成网表失败）；**工作区文件夹名可以中文**。
- **优化写回参数一律保留 1 位小数**，并**保留 `tune{}`/`notune{}`**；取整后复核硬约束。
- 指标类数字（DE%、Pout dBm、距离 Ω）**按其自然精度**，不受"1 位小数"限制。

## 2. 电路与器件（本项目）
- 器件：**CGH40010F**（10 W GaN HEMT，模型 `CGH40010F_r6`）；`Vds=28 V`、`Vgs≈−2.8 V`（**以网表实测为准**，历史上出现过 −2.7 的旧记录）。
- 板材：**RO4350B**；微带用 `MSub1`；常见元件 `MLIN2/MTEE_ADS/MCORSO/MLOC2/MCFIL/MSTEP/MRSTUB/GCM15`。
- 工作频段（本项目常见）：**基波 1.5–2.5 GHz，二次谐波 3–5 GHz**；阻带常取 **5.2–8 GHz**。

## 3. 连续 F 类（CCF）目标空间（**简化轨迹**）
以 **`R_opt`** 为尺度：
| 谐波 | 目标（归一化） |
|---|---|
| **基波** | `R = 2.312·R_opt`（恒定），`X: 0 → −2.002·R_opt` |
| **二次** | `R ≈ 0`，`X: 0 → +3.181·R_opt`（近似纯电抗，落在 Smith **外圆**）|
- `R_opt` 常取 **30 Ω**（**未获用户确认**；CGH40010F@28 V 的常见估计为 **≈26.5 Ω 或 39.2 Ω**）。
- **`R_opt` 的不确定度**应并入空间（对 `R_opt` 采样成**并集**：基波成"扇形"、二次成"带"）⇒ 距离取**并集的最小值**；并**并入 `R_opt` 自身**以免并集不是超集。
- **容差**：对"到轨迹的距离"做 `d_eff = max(0, d − TOL)` 等价于把轨迹**等向膨胀成允许区域**；用户曾定 **`TOL = 0.15·R_opt`（=4.5 Ω）**。
- ⚠ **`R_opt` 扇形对基波极有效，对二次几乎无效**（因为二次目标 `R=0` 是纯电抗线，缩放 `R_opt` 只改 `X`）⇒ 二次要进空间，靠"给 `R` 容差"或**结构改动**。

## 4. 更丰富的"扩展型"目标空间（可选）

除上面的标准 CCF 轨迹外，文献里还有**参数化的扩展型空间**（例如以形状/深浅/扫描参数张成的轨迹族）。
这类空间的定义、公式与目标区间**属于具体文献的内容** —— 本仓库**不收录**。
若你要用某一篇文献的空间作为目标，请**按其原文实现**，并注意：

- 该类空间通常是**归一化**的（例如用电流波形的傅里叶系数作尺度）⇒ **不依赖 `R_opt` 这种绝对假设**，适合做出版图；
- 与"绝对欧姆距离"口径**不要混用**；
- 复现时**必须核对原点/归一化**，否则轨迹会整体缩放。
