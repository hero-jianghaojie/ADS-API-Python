# 08 踩坑与教训（**全部已验证** —— 建议先扫一遍）

> 格式：**症状 → 原因 → 对策**。★ 越多越值钱。

## ADS / 网表 / 写回
1. ★★★ **`Expression 'OUT_W' is already defined`（hpeesofsim 拒绝展开）** → 写回时"写到第一个 VAR 实例"，而单元有 5 个 VAR 块 → **按名字路由**到含该变量的 VAR 块；写前备份、写后逐字节核对（除优化集外必须一致）。
2. ★★ **写回把 `GAP_W/GAP_S` 从 0.625/0.25 变成 0.6/0.3** → 1 位小数取整波及了不属于优化集的变量 → **只对优化集取整**，其余保持 bit-exact。
3. ★★ **`DesignMode.WRITE` 写出空 design** → API 语义 → 用 **`APPEND`**；pcell 参数值**必须传字符串**（`"18.6164 mm"`）。
4. ★★ **"用户说改了，我 diff 却是零差异"** → 基准取成了**改动之后**的导出 → **先用文件 mtime 建时间线，基准取到其改动之前**；工具时间戳是 **UTC**，与用户时钟比要 **+8**。
5. ★★ **看不出拓扑改动** → 只比行数不够（行数几乎不变）→ **统计元件前缀计数**（`MCROSO −1`/`MRSTUB +1`/`MSTEP +2` 这类）。

## 仿真口径 / 数据读取
6. ★★★ **`argmin(|f−f_target|)` 越界 ⇒ 静默返回扫频上沿**，`stop` 掩码为空集 ⇒ **出来的是"貌似合理的垃圾"** → 评估器**必须先断言 `min ≤ band ≤ 2·band ≤ stop ≤ max`**。（真实事故：打分副本只扫到 3.5 GHz，而要看 5 GHz 二次谐波与 8 GHz 阻带。）
7. ★★★ **"你仿真和我为什么不一样"** → 单元 `FundOversample=1`，我用 8 ⇒ 2.40–2.50 GHz 最大差 8.96 个点，把 DE 最差 60.26% 翻成 59.64% → **统一 OS 再比**，并把"口径"写进结论。
8. ★★ **`Pdc` 取错行** → 必须取 **`freq=0` 的 DC 行**；`Pdel` 取**基波行**。

## 优化
9. ★★★ **罚项式代价会卖掉已达标规格** → `mean(deficit)` 被 1/N 稀释；起点在某规格上不可行时加权重也没用 → **把已达标项做成"拒绝式硬地板"**，只优化未达标项；**每次评估打印违规计数**以证实地板被守住。
10. ★★★ **最优解精确贴在地板上（DE 最差 60.0046%）** → 拒绝式地板的天然后果 → **报告达标余量**，必要时用留余量的地板（60.3）。
11. ★★★ **补丁字符串未匹配 ⇒ 静默沿用旧逻辑、白跑一轮** → 文件已被上次改动过 → **按文件当前文本改**，改后**回读确认**。
12. ★★ **MATLAB 驱动 vs Python 驱动** → MATLAB `system()` 32 次只成功 3 次 → **用 Python 模式搜索**；但**采用 ADS `Goal` 里的被测量**。
13. ★★ **"并集反而更远"的悖论** → 采样集不含参考配置 ⇒ 并集不是超集 → **把参考 `R_opt` 并入采样**。
14. ★★ **单规格目标只是把指标在带内搬运**（低频 +0.4 dB 换中频 −0.4 dB）→ **必须看逐点增量**，不能只看最差。

## 运行环境 / Windows
15. ★★ **弹命令窗口** → 子进程没抑制控制台 → Python `creationflags=CREATE_NO_WINDOW (0x08000000)` + Node `windowsHide:true`（**两端都要**）。
16. ★★ **`detached` 进程活不过一步** → 平台限制 → 用**后台 job** 长跑。
17. ★★ **matplotlib 报 `Could not determine home directory`** → 子进程缺 HOME → 传 `HOME`/`USERPROFILE`/`MPLCONFIGDIR`。
18. ★★ **`Tee-Object` 日志读成乱码** → 它是 **UTF-16** → 用 `utf16le` 读（或先看 `\u0000` 密度）。
19. ★ **桥接进程不能跑仿真**（`run_hpeesofsim` 在此环境失败）→ **导网表走桥接、仿真走 ADS 的 python**。
20. ★ **TS/JS 没有 `1j` 字面量** → 复数用**实部运算**；`run_code` 里报 `Identifier cannot follow number` 就是这个。

## 图表 / 通用
21. ★★★ **"按某张已有图的风格出图"** → 手画 ✗ → **先到源项目里找它的生成脚本，只换数据源**（本轮把任务从"重写绘图"变成"换数据"）。
22. ★★ **复用他人脚本要"用它自己的 venv + 数据放到它期望的路径"**（改它内部路径常不生效；改输出名避免覆盖）。
23. ★★★ **用"候选设计（未写回）"出的图被误当成单元现状** → **图变体按"编码哪套值"命名**（`_user`/`_cell`/无后缀=优化后）。
24. ★★ **换算类结果要用"用户已公布的某个数"自证**（`|S11|∠θ→Z` 与 ADS 标注逐位一致后，整图才可信）。
25. ★★ **用户说"很好"而我的指标说更差** → 先怀疑**口径不一致**，**问其判据**，不要反复重申自己的尺子。
26. ★★ **要"把某匹配放进某单元"但只给了曲线** → **`S11(f)` 不能唯一确定网络** → **必须索取设计（网表/单元）**；先做**身份比对**（候选 × 端口置换，并给出"随机水平"作参照；误差比随机更差 = 形状反相关）。
