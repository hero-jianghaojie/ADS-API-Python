# ADS 自动化与优化 —— 交接包（给另一台电脑上的 AI 读）

> 目的：让**任何一台电脑上的 AI** 在 **30 分钟内**看懂"我们一直在做什么、怎么做、哪里会踩坑"，
> 并能**照着复现**：导出/改 ADS 单元 → 跑仿真 → 优化 → 验证 → 出图 → 写回。

## 0. 一句话总览
我们在 **Keysight ADS 2025 Update2** 上，用 **Python 脚本**驱动"**导出网表 → 打补丁 → 调 hpeesofsim → 读数据集 → 算指标 → 优化 → 写回单元**"这条闭环，做**射频功放(PA)/滤波器(BPF)**的设计与优化；EM/版图侧用 **Momentum/联合仿真**，但**几何重生成必须走 GUI**（见 05）。

## 2. 最小可用闭环（伪代码）
```python
# 1) 用桥接把 ADS 单元导出为网表（.net）
#    <BRIDGE_PY> pb.py <script.py>   # 脚本里 db.Design(lib,cell,view).generate_netlist()
# 2) 用文本补丁改变量（网表是纯文本： ^VAR=1.234  ->  ^VAR=2.0）
# 3) 用 ADS 自带 python 调 hpeesofsim 跑，产出数据集(.ds)
#    <ADS_HOME>/tools/python/python.exe
# 4) 读数据集(keysight.ads.dataset) -> 算指标(如 PA 的 DE/Pout) -> 优化循环
# 5) 更优则"按名字路由"写回 ADS 单元（只对优化集取 1 位小数），再复测
```

## 3. 三条铁律（违反必踩坑，详见 08）
1. **桥接进程只能导网表/改设计，不能跑仿真** ⇒ 仿真必须用 ADS 的 python。
2. **扫频类评估器必须让网表扫频覆盖它读的每个量**（越界会静默取到扫频上沿，出来的是"貌似合理的垃圾"）。
3. **已达标指标要做"拒绝式硬地板"**，只对未达标指标做目标；否则优化器会把它卖掉。

## 4. 单位与命名（用户硬性偏好）
- **布局单位一律 毫米(mm)**；**库/单元/视图/网络/端口/变量/数据集名一律英文 ASCII 小写+下划线**；工作区**路径也要全 ASCII**（中文名会让 hpeesofsim/Momentum 生成网表失败）。
- **优化写回的参数一律保留 1 位小数**，且保留 `tune{}`/`notune{}` 注解。
- **凡有数据表格必须同时出图**：英文标注、PNG+SVG 双出、直接从已存 JSON 出图。
