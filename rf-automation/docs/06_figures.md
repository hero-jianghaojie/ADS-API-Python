# 06 出图规范（用户硬性偏好 + 复用既有绘图脚本的招）

## 1. 铁律
1. **报告图统一英文标注**（matplotlib 默认字体**无 CJK**，中文会变方框）。
2. **PNG + SVG 双出**（SVG 进文献）。
3. **直接从已存 JSON 出图**，不重跑仿真（秒级、可反复改版）。
4. **量纲不同不共轴**（`twinx()` 或拆图）。
5. 跨 **≥3 个数量级用对数轴**。
6. **对比图不得编造数据**：未知上界只标 `≥`/`~` 并注明来源。
7. **"拆解"类数据**（如 失配损耗 vs 耗散损耗）用**堆叠/分组条形图**。
8. 凡有数据表格 ⇒ **同时给图**。

## 2. 子进程出图的必带环境
```python
env = {**os.environ, "HOME": r"C:\Users\<you>", "USERPROFILE": r"C:\Users\<you>",
       "MPLCONFIGDIR": r"<可写目录>"}
```
否则：`RuntimeError: Could not determine home directory.`

## 3. ★ 要"按某张已有图的风格"出图时 —— **先找它的生成脚本**
- 本项目实例：一张既有图（某文献的参数化 Smith 图）⇒ 在其既有工程里找到
  `scripts/plot_smith_target-spaces_output_combined.py`（就是"**target-space σ 扫描 + 输出阻抗 合成**"）⇒ **只换数据源**即可，样式/图例/归一化**一字不改**。
- **复用他人脚本的正确姿势**：
  1. **用它自己的解释器/venv**（本例 `<your-paper-project>\.venv`，内有 `skrf 2.1.0`）；
  2. **把数据放到它期望的路径/文件名**（别去改它内部路径 —— 实测改名字段不生效，直接把数据复制成它要的名字最省事）；
  3. **只改输出文件名**，避免覆盖已有图；
  4. 运行前给它带 `HOME`/`USERPROFILE`/`MPLCONFIGDIR`。
- **【重要】图变体要按"编码哪套值"命名**：
  例：`…_user.*`＝用户给的数据；`…_cell.*`＝单元现值；`…`＝优化后（未写回）。**混在一起会被误当成同一个设计**。

## 4. Smith 图
- 网格用 `skrf.plotting.smith(ax=ax, draw_labels=False)`（出版风格）；
- 画 `Γ=(Z-Z0)/(Z+Z0)` 后 `set_rlim(0,1.02)`；标注常用频点用标记 + 文字。

## 5. 数据换算的"自证"要求
把 `|S11|∠θ` 换成 `Z=R+jX`：`Z = Z0(1+Γ)/(1-Γ)`，`Γ=|S11|e^{jθ}`
（在 JS/TS 里做复数用**实部运算**：`Z/Z0 = [(1-a²-b²) + j·2b]/[(1-a)²+b²]`，`a=m·cosθ, b=m·sinθ` —— **TypeScript 没有 `1j` 字面量**）。
**必做**：算完拿**用户已公布的某个数**对一下（例：1.500 GHz 算出 `72.858−j36.581 Ω` 与用户 ADS 标注`impedance = 72.858−j…` 逐位一致 ⇒ 整张图才可信）。
