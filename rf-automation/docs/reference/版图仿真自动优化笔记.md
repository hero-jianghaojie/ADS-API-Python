## 1. 🔄 原理图优化 vs 版图优化

| 方面               | 原理图优化             | 版图优化                  |
| :----------------- | :--------------------- | :------------------------ |
| **仿真类型** | 电路仿真（hpeesofsim） | EM 仿真（Momentum/RFPro） |
| **速度**     | 快（几秒/次）          | 慢（几分钟~几小时/次）    |
| **精度**     | 准确（基于模型）       | 更准确（全波电磁）        |
| **优化变量** | VAR 变量（L、W、S 等） | 版图几何形状              |
| **适合场景** | 初步设计、参数优化     | 最终验证、EM 效应         |
| **工具**     | `demo_opt_var_auto`  | EM 优化器 / 脚本          |

### 💡 推荐流程

```
原理图优化 (demo_opt_var_auto)
    ↓
最优 VAR 值
    ↓
ADS 自动生成版图
    ↓
EM 仿真验证 (Momentum/RFPro)
    ↓
如需微调 → 回到原理图优化
```

## 2. 📊 版图优化工作流程

### 2.1 标准流程

```
1. 原理图设计 → 优化 VAR 变量
2. 生成版图（自动或手动）
3. 版图参数化（绑定 VAR 变量）
4. 设置 EM 仿真（Momentum/RFPro）
5. 运行 EM 仿真
6. 读取 S 参数结果
7. 优化循环：调整参数 → 重新仿真 → 评估
8. 输出最优版图
```

### 2.2 关键步骤说明

#### 步骤 1：原理图优化

使用 `demo_opt_var_auto` 优化 VAR 变量，得到最优值。

#### 步骤 2：生成版图

在 ADS 中：

- **方法 A**：原理图 → 版图（自动转换）
- **方法 B**：直接绘制版图（手动）

#### 步骤 3：版图参数化

将版图几何尺寸绑定到 VAR 变量：

- 线长 → L1, L2, ...
- 线宽 → W1, W2, ...
- 间距 → S1, S2, ...

#### 步骤 4：EM 仿真设置

配置 Momentum 或 RFPro：

- 衬底参数（介电常数、厚度）
- 端口设置
- 频率范围
- 网格密度

#### 步骤 5：运行 EM 仿真

通过 Python API 或 GUI 运行仿真。

#### 步骤 6：读取结果

从 dataset 中提取 S 参数。

#### 步骤 7：优化循环

调整参数 → 重新仿真 → 评估 → 重复。

## 3. 🔧 版图参数化方法

### 3.1 版图中的变量绑定

在 ADS 中，版图几何尺寸可以绑定到 VAR 变量：

```
VAR1:
  W1 = 0.3      # 线宽
  S1 = 0.1      # 间距
  L1 = 4.2      # 长度
  L2 = 5.7      # 长度
```

### 3.2 版图参数化示例

#### 微带线滤波器

```
┌─────────────────────────────┐
│  W1                          │
│  ├─────── L1 ───────┤       │
│                      │ S1    │
│  ├─────── L2 ───────┤       │
│  W2                          │
└─────────────────────────────┘
```

变量绑定：

- `W1` → 第一段线宽
- `L1` → 第一段长度
- `S1` → 间距
- `L2` → 第二段长度
- `W2` → 第二段线宽

### 3.3 版图参数化的优势

1. **一致性**：原理图和版图使用相同变量
2. **自动化**：修改变量自动更新版图
3. **优化**：可以直接优化版图参数

## 4. 🚀 EM 仿真设置（Momentum/RFPro）

### 4.1 Momentum 仿真

Momentum 是 ADS 的矩量法 EM 仿真器，适合平面电路。

#### 设置步骤

1. **打开版图**：`Study_lib:circle:layout`
2. **设置衬底**：定义介质层、金属层
3. **设置端口**：定义输入/输出端口
4. **设置频率**：定义扫频范围
5. **运行仿真**

#### Python API 设置

```python
from keysight.ads import de, ael

# 打开版图
ws = de.open_workspace(wrk_path)
lib = ws.open_library("Study_lib")
cell = lib.find_cell("circle")
layout_view = cell.find_view("layout")

# 打开设计窗口
win = ael.call.deOpenDesign(layout_view)

# 设置衬底
ael.call.deSetSubstrateParams(win, "MSub1",
    "H", "0.508 mm",
    "Er", "3.55",
    "TanD", "0.001")

# 设置端口
ael.call.deNewPort(win, "Port1", 100, 200, "External")
ael.call.deNewPort(win, "Port2", 500, 200, "External")

# 运行仿真
ael.call.deSimulate(win)
```

### 4.2 RFPro 仿真

RFPro 是 ADS 的高级 EM 仿真工具，支持更复杂的结构。

#### RFPro 设置

```python
# 打开 RFPro
ael.call.deOpenRFPro(cell)

# 设置仿真参数
ael.call.deSetRFProParam(win, "minFreq", "1 GHz")
ael.call.deSetRFProParam(win, "maxFreq", "10 GHz")
```

### 6.2 完整优化脚本（带 EM 仿真）

```python
#!/usr/bin/env python
"""
完整版图 EM 仿真自动优化脚本
支持 Momentum 和 RFPro
"""
import os
import sys
import time
import numpy as np
from scipy.optimize import minimize, differential_evolution
from keysight.ads import de, ael, dataset

class LayoutOptimizer:
    def __init__(self, wrk_path, lib_name, cell_name):
        self.wrk_path = wrk_path
        self.lib_name = lib_name
        self.cell_name = cell_name
        self.cell = None
        self.var_names = []
        self.var_defaults = []
        self.var_bounds = []
      
    def setup(self):
        """初始化设置"""
        de.open_workspace(self.wrk_path)
        lib = de.get_open_library(self.lib_name)
        self.cell = lib.find_cell(self.cell_name)
      
        # 获取变量信息
        layout_view = self.cell.find_view("layout")
        win = de.open_design(layout_view)
      
        # 读取 VAR 变量
        var_inst = ael.call.deFindInst(win, "VAR1")
        for var in var_inst.vars:
            self.var_names.append(var.name)
            self.var_defaults.append(float(var.value))
            # 设置默认边界（±40%）
            val = float(var.value)
            self.var_bounds.append((val * 0.6, val * 1.4))
      
        de.close_design(win)
  
    def set_variables(self, values):
        """设置变量值"""
        layout_view = self.cell.find_view("layout")
        win = de.open_design(layout_view)
      
        for name, value in zip(self.var_names, values):
            ael.call.deSetVar(win, "VAR1", name, str(value))
      
        win.update()
        de.close_design(win)
  
    def run_em_simulation(self, sim_type="momentum"):
        """运行 EM 仿真"""
        layout_view = self.cell.find_view("layout")
        win = de.open_design(layout_view)
      
        if sim_type == "momentum":
            # Momentum 仿真
            ael.call.deSimulate(win)
        elif sim_type == "rfpro":
            # RFPro 仿真
            ael.call.deOpenRFPro(self.cell)
            ael.call.deSimulateRFPro(win)
      
        # 等待仿真完成
        self._wait_for_simulation()
      
        de.close_design(win)
  
    def _wait_for_simulation(self):
        """等待仿真完成"""
        # 实现等待逻辑
        time.sleep(5)  # 简单等待
  
    def read_results(self):
        """读取仿真结果"""
        ds_path = os.path.join(self.wrk_path, "data", f"{self.cell_name}.ds")
      
        if not os.path.exists(ds_path):
            raise FileNotFoundError(f"Dataset 不存在: {ds_path}")
      
        ds = dataset.open(ds_path)
      
        # 提取 S 参数
        # 这里需要根据实际 dataset 结构实现
        # 示例：
        freq = ds["freq"].values / 1e9  # Hz → GHz
        s11 = 20 * np.log10(np.abs(ds["S[1,1]"].values) + 1e-30)
        s21 = 20 * np.log10(np.abs(ds["S[2,1]"].values) + 1e-30)
      
        return freq, s11, s21
  
    def evaluate_cost(self, values, freq_range=(2.0, 4.0), 
                      s11_max=-15.0, s21_min=-1.0):
        """评估代价函数"""
        # 设置变量
        self.set_variables(values)
      
        # 运行仿真
        self.run_em_simulation()
      
        # 读取结果
        freq, s11, s21 = self.read_results()
      
        # 提取目标频段
        idx = np.where((freq >= freq_range[0]) & (freq <= freq_range[1]))[0]
      
        if len(idx) == 0:
            return 1000.0  # 无效频段
      
        s11_worst = np.max(s11[idx])
        s21_worst = np.min(s21[idx])
      
        # 计算代价
        cost = 0.0
        if s11_worst > s11_max:
            cost += 1.5 * (s11_worst - s11_max)
        if s21_worst < s21_min:
            cost += 1.0 * (s21_min - s21_worst)
      
        return cost
  
    def optimize(self, method="L-BFGS-B"):
        """执行优化"""
        x0 = self.var_defaults
      
        if method == "L-BFGS-B":
            result = minimize(
                self.evaluate_cost,
                x0,
                method='L-BFGS-B',
                bounds=self.var_bounds,
                options={'maxiter': 50, 'disp': True}
            )
        elif method == "differential_evolution":
            result = differential_evolution(
                self.evaluate_cost,
                bounds=self.var_bounds,
                maxiter=30,
                tol=0.01,
                disp=True
            )
      
        return result
  
    def save_results(self, result):
        """保存优化结果"""
        # 保存到文件
        output = {
            "var_names": self.var_names,
            "optimal_values": result.x.tolist(),
            "cost": result.fun
        }
      
        import json
        with open(f"{self.cell_name}_layout_opt.json", "w") as f:
            json.dump(output, f, indent=2)
      
        print(f"结果已保存: {self.cell_name}_layout_opt.json")

def main():
    # 创建优化器
    optimizer = LayoutOptimizer(
        wrk_path=r"<MATLAB_ADS>\work\Study_wrk",
        lib_name="Study_lib",
        cell_name="circle"
    )
  
    # 初始化
    optimizer.setup()
  
    # 执行优化
    result = optimizer.optimize(method="L-BFGS-B")
  
    # 保存结果
    optimizer.save_results(result)
  
    print(f"优化完成! 最终代价: {result.fun}")

if __name__ == "__main__":
    main()
```

### 7.1 优化方法

**原理**：circle 版图由原理图 VAR 变量参数化，因此优化 VAR 变量 = 优化版图几何。

**脚本**：`layout_opt_circuit.py`（纯 Python，无需 MATLAB）

- 打开原理图 → 设置 VAR → 生成网表 → `hpeesofsim` 仿真 → 读 S 参数 → 评估代价 → 迭代
- 随机搜索 + 局部精调（围绕当前最优 ±10%）
- 参数保留 2 位小数

**运行方式**：

```python
from keysight.edatoolbox import multi_python

def probe_rfpro(workspace_name, lib, cell, view):
    import empro
    from keysight.edatoolbox import xxpro
    from keysight.edatoolbox.ads import LibraryCellView

    xxpro.use_workspace(workspace_name)
    pro = LibraryCellView(library=lib, cell=cell, view=view)
    xxpro.load_pro_view(pro)

    with empro.activeProject as project:
        return {
            "location": str(project.location),
            "n_geometries": len(project.geometry),
            "n_params": len(project.parameters),
            "n_analyses": len(project.analyses),
        }

# 使用
with multi_python.xxpro_context() as caller:
    result = caller.call(probe_rfpro, args=[workspace_path, "Study_lib", "circle", "rfpro"])
```
