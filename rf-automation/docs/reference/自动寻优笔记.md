## 1. 🔧 通用 VAR 工具（自动发现所有 VAR 变量）

原理图里的变量存在 **Var Eqn 实例**（如 VAR1、VAR2…）里，数量、命名都不固定。下面 4 个函数让你**不用关心变量在哪个 VAR、有几个 VAR**，直接用"变量名"操作。

| 函数 | 作用 | 示例 |
|:---|:---|:---|
| `ads_var_read(d)` | 枚举所有 VAR 实例及其变量**当前值** → `{VAR名, 变量名, 值}` | `T = ads_var_read(d); disp(T);` |
| `ads_var_list(d)` | 按 VAR 分组**列出所有变量名** → struct 数组 | `out = ads_var_list(d);` |
| `ads_var_set(d, {名,值;...})` | 按**变量名设参**（可只给部分），自动分组到所属 VAR | `ads_var_set(d, {'L1', 9.07; 'W3', 1.61});` |
| `ads_var_set_all(d, 值向量)` | **一次性全设**（值向量按 `ads_var_read` 顺序，长度须一致） | `ads_var_set_all(d, [9.07 90 ...]);` |

> 📊 **实测**（Study_lib:INPUT）：自动发现 **2 个 VAR、14 个变量**。

```matlab
T = ads_var_read(d); disp(T);                     % 读出所有变量当前值
out = ads_var_list(d);                            % 列出所有 VAR 及变量名
ads_var_set(d, {'L1', 9.07; 'W3', 1.61});         % 按名设参（部分）
ads_var_set_all(d, [9.07 90 1.61 2.84 10 ...]);   % 按顺序一次性全设
```

## 2. 🔄 手动联合仿真闭环（分步）

```matlab
% ═══════════════════════════════════════════════════════════════
% [1] 初始化桥接（不要 venv 终端启动 MATLAB）
% ═══════════════════════════════════════════════════════════════
cd('<MATLAB_ADS>');
[de, ds] = ads_init();

% ═══════════════════════════════════════════════════════════════
% [2] 打开工作区 + 设计（APPEND=允许保存）
% ═══════════════════════════════════════════════════════════════
ws = de.open_workspace('<MATLAB_ADS>\work\Study_wrk');
d  = ws.design('Study_lib:INPUT:schematic', de.db.DesignMode.APPEND);

% ═══════════════════════════════════════════════════════════════
% [3] 看参数：VAR 变量（自动发现所有 VAR，推荐）
% ═══════════════════════════════════════════════════════════════
out = ads_var_list(d);                                % 所有 VAR 及变量名
T = ads_var_read(d); disp(T);                         % 所有变量当前值
% （可选）直接读单个实例参数：char(d.find_instance('TL1').parameters('L').value)

% ═══════════════════════════════════════════════════════════════
% [4] 设参数：VAR 变量（推荐）
% ═══════════════════════════════════════════════════════════════
% ── 方式A：按名设参 / 一次性全设 ──
ads_var_set(d, {'L1',9.07; 'W3',1.61; 'SL1',10});   % 按变量名设参（部分）
ads_var_set_all(d, [9.07 90 1.61 2.84 10 1.61 1.61 0.587 7.07 2.47 5.39 4.43 1.61 3.53]); % 一次性全设

% ── 方式B（最省事）：全部 VAR 参数 -> 工作区同名变量，改完一次性写回 ──

ads_var_export(d);                                % 全部写回原理图
%ads_var_import(d);                                % L1=9.0692, W1=1.6123, SL1=10, ... 出现在工作区
%L1 = 9.07; W3 = 1.61; SL1 = 10;                   % 直接改 MATLAB 变量
% ── 方式C（旧/底层写法）──
% ads_set_param(d, {'TL1','L','14.22 mm'; 'Stub1','L','10 mm'}); % 直接实例参数（不经 VAR）
% ads_set_var(d, 'VAR1', {'L1','SL1'}, [14.22 10]);              % 指定 VAR 设参（需写死 VAR1）

% ═══════════════════════════════════════════════════════════════
% [5] 仿真（核心）：生成网表 -> hpeesofsim -> 读回
% ═══════════════════════════════════════════════════════════════
out = ads_run_sim(d, '<MATLAB_ADS>\work\Study_wrk', 'INPUT');

% ═══════════════════════════════════════════════════════════════
% [6] 算指标（S11/S21 @ 目标频点）
% ═══════════════════════════════════════════════════════════════
f = out.data.freq_ghz; i0 = find(abs(f-3.0)<=0.05,1);
s11dB = 20*log10(abs(out.data.S.S_1_1(i0))+1e-30);
s21dB = 20*log10(abs(out.data.S.S_2_1(i0))+1e-30);
fprintf('S11@3GHz=%.2f dB  S21@3GHz=%.2f dB\n', s11dB, s21dB);
```

> 💡 **闭环逻辑**：改参数 → `ads_run_sim` → 读 `out.data.S` → 重复该循环即手动寻优。
>
> ⚠️ **注意**：设实例参数用 `ads_set_param`（值带单位）；设 VAR 变量用 `ads_var_set` / `ads_var_set_all`。

## 3. 🚀 自动寻优：设置目标要求 → 自动循环

`demo_opt_var_auto` 自动完成：`ads_var_read` 发现全部 VAR 变量 → `fminsearch` 循环
（每轮 `ads_var_set` 全设 → `ads_run_sim` → 读 S11/S21 → 代价）→ 满足/收敛后写回。

```matlab
% ═══════════════════════════════════════════════════════════════
% 方式A：S11/S21 都写在括号里（对称）
% ═══════════════════════════════════════════════════════════════
demo_opt_var_auto(3.0, [], true, ...
    's11_max', -20, ...                 % S11 要求：<= -20 dB
    's21_min', -1, ...                  % S21 要求：>= -1 dB
    'Exclude', {'Deg1'});               % 排除角度变量

% ═══════════════════════════════════════════════════════════════
% 方式B：S11 用第 2 个位置参数
% ═══════════════════════════════════════════════════════════════
demo_opt_var_auto(3.0, -20, true, ...
    's21_min', -1, ...
    'Exclude', {'Deg1'});

% ═══════════════════════════════════════════════════════════════
% 方式C：优化 OUTPUT cell
% ═══════════════════════════════════════════════════════════════
demo_opt_var_auto(3.0, -20, true, ...
    'cell', 'Study_lib:OUTPUT:schematic', ...
    's21_min', -1, ...
    'Exclude', {'Deg1'});
```

### 📋 参数总览

| 参数 | 默认值 | 说明 |
|:---|:---:|:---|
| `freq_ghz`（位置1） | `3.0` | 目标频点 (GHz) |
| `s11_max`（位置2 / `'s11_max'`） | `-20` | S11 要求 ≤ 该值 (dB) |
| `writeback`（位置3） | `true` | 是否把最优值写回原理图并保存 |
| `'s21_min'` | `-3` | S21 要求 ≥ 该值 (dB) |
| `'ef'` | `l1` | 误差函数（借鉴 ADS EF）：`l1`/`lsq`/`minimax`/`pth` |
| `'bands'` | 自动以 freq_ghz 为中心生成 ±0.1GHz 频段 | 多频段约束（借鉴华为损失函数）：cell，每项 `{f_lo,f_hi,s11_max,s21_min}`(GHz,dB)；某阈值传 `[]` 表示该段不约束该项；不传则自动生成以 freq_ghz 为中心的频段（宽度由 `'band_width'` 控制） |
| `'band_width'` | `0.2` | 默认频段宽度(GHz)，仅当 `'bands'` 未指定时生效，生成 freq_ghz ± band_width/2 的频段 |
| `'LB'` / `'UB'` | 当前值 `0.6x`/`1.4x` | 变量上下界（长度=变量数） |
| `'Exclude'` | `{}` | 排除不优化的变量（如角度 `Deg1`） |
| `'MaxIter'` / `'MaxFunEvals'` | `150` / `200` | 迭代 / 总求值次数上限 |
| `'solver'` | `patternsearch` | 优化器（详见下方[算法对比](#-算法对比与推荐昂贵仿真场景)） |
| `'cell'` | `'Study_lib:INPUT:schematic'` | 目标 cell 名称，如 `'Study_lib:OUTPUT:schematic'` |
| `'fname'` | `<cell>_opt` | 输出图名前缀 |

> 📌 **示例**：`'bands', {{2.8,3.2,-20,-3},{3.5,4.0,-10,-20}}`

### 💰 判定原理（代价函数）

$$
\text{cost} = 1.5 \cdot \max(0, S_{11} - s11\_max) + 1.0 \cdot \max(0, s21\_min - S_{21})
$$

```matlab
cost = 1.5*max(0, S11 - s11_max) ...   % S11 越界才惩罚，权重 1.5
     + 1.0*max(0, s21_min - S21);      % S21 越界才惩罚，权重 1.0
```

| 条件 | 含义 |
|:---:|:---|
| `cost = 0` | ✅ 两个要求都满足 |
| `S11` 权重 `1.5` | 🎯 优先压回波损耗 |
| `S21` 权重 `1.0` | 📡 其次保证传输系数 |

### 📊 算法对比与推荐（昂贵仿真场景）

> ⚠️ **核心原则**：每轮代价 = 一次 ADS 仿真，所以「更快更好」= **用更少的仿真次数达到目标**。
>
> ✅ **你的机器三个工具箱都齐**（已实测 license=1），可直接切换求解器。

| 求解器 | 算法 | 特点 | 适用场景 | 工具箱 |
|:---|:---|:---|:---|:---|
| `patternsearch` ⭐ | 模式搜索 | 全局+局部、**原生支持边界**、稳健 | 🏆 **默认 / 稳健首选** | Global Optimization |
| `fminsearch` | Nelder-Mead | 无导数、局部、无约束 | 备用 | 内置 |
| `ga` | 遗传算法 | 全局随机搜索（借鉴 ADS Genetic） | 地形复杂、局部极小多 | Global Optimization |
| `simulannealbnd` | 模拟退火 | 全局、**从 X0 出发**（借鉴 ADS SA） | 参数多、局部极小多 | Global Optimization |
| `hybrid` | 遗传→patternsearch | 先全局粗搜再局部精调（借鉴 ADS Hybrid） | 要全局又要精 | Global Optimization |
| `surrogateopt` | 代理模型 | Kriging/RBF；**从随机采样起步**，高维+小预算易退化 | ⚠️ 低维+预算充足 | Global Optimization |
| `bayesopt` | 贝叶斯优化 | GP + expected improvement；维度>10 建议降维 | ⚠️ 低维高价值 | Statistics+ML |

> 🧪 **2026-08-17 实测对比**（13 维、预算 40、目标 S11≤-40dB）：
>
> | 求解器 | 起点 | 结果 |
> |:---|:---:|:---:|
> | `patternsearch` / `fminsearch` / `simulannealbnd` | X0 = -35dB | ✅ 保持 -35dB 达标 |
> | `surrogateopt` / `bayesopt` | 随机采样 | ❌ 退化到 -6.5dB |
>
> 💡 **结论**：你的场景（13 维 + 昂贵仿真 + 已有好起点）**默认用 `patternsearch`**；
> `surrogateopt`/`bayesopt` 仅在**降维(≤8 维)且预算充足**时考虑。

> 📚 **借鉴 ADS 13 种优化算法**（知乎《ADS 中 13 种优化算法的区别》）：
> - ADS 算法 = 误差函数(EF) × 搜索方法
> - 我们把代价函数做成 4 种 EF：`l1`/`lsq`/`minimax`/`pth`
>   （对应 ADS 的 L1/L2、Least-Squares、Minimax、Least Pth）
> - 求解器补齐 ADS 的 Genetic(`ga`)、SA(`simulannealbnd`)、Hybrid(`hybrid`) 三类全局搜索

```matlab
% ── 换求解器只需加 'solver' ──
demo_opt_var_auto(3.0, [], true, ...
    's11_max', -20, 's21_min', -1, 'Exclude', {'Deg1'}, ...
    'solver', 'surrogateopt');   % 或 'patternsearch' / 'bayesopt'
```

> 🛠️ **工程捷径**：微波匹配网络常先用 Smith Chart / 解析设计给初值，再局部精调（相当于只跑少量仿真）——仿真次数最少。

### 📡 多频段约束（默认模式，借鉴华为损失函数）

> 📚 **参考**：华为《基于AI的射频及天线设计》里滤波器/匹配设计的目标都是**通带 + 带外多频段**约束
> （损失函数 $K=\max[(S_{11})_{PB},-RL]+w\cdot\max[(S_{21})_{SB},-IL]$）。
> 我们的 `'bands'` 把代价函数升级为**任意多个频段**同时约束，配合 `ef` 聚合。
> 
> 💡 **默认行为**：不传 `'bands'` 时，自动以 `freq_ghz` 为中心生成 ±0.1GHz 频段（可通过 `'band_width'` 调整宽度）。

```matlab
% ── 默认频段模式（自动以 freq_ghz 为中心 ±0.1GHz）──
demo_opt_var_auto(3.0, [], true, ...
    's11_max', -20, 's21_min', -1, ...
    'Exclude', {'Deg1'});

% ── 自定义频段宽度（±0.2GHz）──
demo_opt_var_auto(3.0, [], true, ...
    's11_max', -20, 's21_min', -1, ...
    'band_width', 0.4, ...
    'Exclude', {'Deg1'});

% ── 显式指定多频段约束 ──
% 通带 2.8-3.2GHz：S11<=-15、S21>=-1
% 带外 3.5-4GHz：S11<=-10、S21<=-20（抑制）
demo_opt_var_auto(3.0, [], true, ...
    'bands', {{2.8,3.2,-15,-1}, {3.5,4.0,-10,-20}}, ...
    'Exclude', {'Deg1'});
```

> 📐 **格式说明**：每段四项 `{f_lo, f_hi, s11_max, s21_min}`；某阈值传 `[]`（如 `{2.8,3.2,-15,[]}`）表示该段不约束该项。
>
> ✅ **已实测**：两段约束下自动识别并收敛，`cost=0` 即全部频段达标。

## 5. ⚠️ 常见坑

| # | 问题 | 解决方案 |
|:---:|:---|:---|
| 1 | **必须 OutOfProcess** | `ads_init` 已处理；否则报 `Failed to load the _pde extension module` |
| 2 | **HPEESOF_DIR 要在 import 前设** | `ads_init` 已处理 |
| 3 | **别在 venv 终端启动** | 会报 `No module named 'keysight'` |
| 4 | **工作区单例 / 残留写锁** | ADS 一次只能打开一个工作区；异常退出会残留，报 `A workspace is already open` 或 `Unable to lock database file`。`demo_opt_var_auto` 开头已自动 `close_workspace()` + `ads_clear_locks` 兜底自愈；手动跑遇到时先 `de.close_workspace()` 重试，仍不行就删 `...\schematic\sch.oa.cdslck`（确认持有进程已死） |
| 5 | **孤儿进程** | `MATLABPyHost.exe` 等可能残留并持有工作区锁；确认无活动 MATLAB 会话后可结束该进程 |
| 6 | **`vtb.defs ... Cannot read` 警告** | 写到 stderr，忽略即可，非错误 ✅ |

## 7. 🐍 纯 Python 自动优化（无需 MATLAB）

> 💡 **新功能**：现在可以直接用 Python 完成全部优化流程，无需打开 MATLAB 和 ADS GUI！

### 快速开始

```bash
# 基本用法（使用默认配置）
cd <MATLAB_ADS>
python auto_optimize.py

# 自定义参数
python auto_optimize.py --freq 3.5 --s11_max -25 --s21_min -1

# 使用配置文件

```

### 8.2 关键知识点提炼（文档 vs 我们的实践）

#### MATLAB-ADS 数据交换的 5 种方式

| # | 方式 | 文档描述 | 我们的现状 | 差距 |
|:---:|:---|:---|:---|:---:|
| ① | 文件交换 | `.s2p` / CSV / MAT | ✅ `read_ads_dataset.m` + `ads_sim_helper.py` | 已超越 |
| ② | COM 接口 | `actxserver('Agilent.Application')` | ❌ 未用 | 可选增强 |
| ③ | MATLAB Script | 生成 Python/Jython 脚本 | ✅ 直接 Python API（更优） | 已超越 |
| ④ | hpeesofsim 引擎 | 命令行调用 | ✅ `ads_run_sim.m` | 完全一致 |
| ⑤ | Co-Simulation 插件 | ADS 内调用 MATLAB 函数 | ❌ 未用 | 可选增强 |

> 📌 **结论**：我们在 ①③④ 三个维度已超越文档描述的方法。COM 接口（②）适合 GUI 控制场景，Co-Simulation 插件（⑤）适合实时数据交换，但对我们当前的闭环优化工作流不是必需的。

#### ADS 优化算法 vs 我们的 MATLAB 求解器

文档介绍的 ADS 内置 13 种优化算法 vs 我们的 `demo_opt_var_auto` 对应：

| ADS 算法 | MATLAB 对应 | 我们的现状 |
|:---|:---|:---|
| Random | — | `surrogateopt` 起步采样类似 |
| Gradient | `fminsearch`（无导数版） | ✅ 已支持 |
| Genetic (GA) | `ga` | ✅ 已支持 |
| Simulated Annealing | `simulannealbnd` | ✅ 已支持 |
| Hybrid (GA→Gradient) | `hybrid` (ga→patternsearch) | ✅ 已支持 |
| Particle Swarm | — | ❌ 未支持（MATLAB 无内置 PSO） |
| **Pattern Search** | `patternsearch` ⭐ | ✅ **默认/首选** |

> 📌 **差距**：ADS 的 PSO（粒子群优化）我们没有 MATLAB 对应。如果需要可考虑 `particleswarm`（Global Optimization Toolbox 内有）。
