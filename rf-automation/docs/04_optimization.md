# 04 优化方法（**本项目的核心经验**）

## 1. 用什么驱动搜索（**都已实测对比过**）
| 方式 | 结论 |
|---|---|
| **MATLAB 调 `system()` 驱动** | ❌ **32 次里只有 3 次成功**（sim fail）⇒ 弃用 |
| **ADS 自带 `Optim` 控制器**（GUI 里那个 `Optim1`/`Goal`）| ❌ 慢，且**无法与"距离口径 + 三处吻合验证"配套** |
| **Python 驱动 + 模式搜索（pattern search）** | ✅ **首选**。逐变量线搜索、单调接受、步长减半、乱序；比随机/局部搜索强（实测：**139 次评估就拿到改进，而 160 次纯随机毫无进展**）|
| ADS `Optim` | ✅ 可留作 **GUI 交叉验证**（跑一遍看是否与我给的结果一致）|

**关键**：**采用截图里 `Goal` 的"被测量"（如 `Zin`），但用 Python 自己算判据**。
- 评估成本参考：**HB 21 点 ≈ 5.5–8 s/次**（大部分是 hpeesofsim 的固定启动开销；**降过采样/降点数几乎不省**）。

## 2. ★ 硬地板（**最重要的一条**）
**当起点已满足规格 A、违反规格 B 时：把 A 做成"拒绝式硬地板"，只对 B 优化。**
- ❌ 反向教训：用 `mean(deficit)` 作罚项 ⇒ **21 点里 1 点违规只算 1/21（被稀释）** ⇒ 优化器**拿 A 换 B**（实测 DE 最差 60.26→59.42）。
- ❌ 把权重加到 **40×** 也没用 ⇒ **因为起点在 B 上不可行，罚项式代价必然牺牲 A**。
- ✅ 正解：`if A.min() < A_floor: return None`（不满足即**不可行**）⇒ 此后**每次接受的点 A 违规恒为 0**。
- ✅ **每次评估都打印各指标**（如"违规 DE 0 点 / Pout 1 点"）⇒ **用它证实地板真被守住**。
- ⚠ 副作用：**最优解会精确贴在地板上**（实测 DE 最差 = 60.0046%）⇒ **必须报告"达标余量"**，必要时把地板设为**留余量值**（如 60.3）或接受裸规格风险。

## 3. 分阶段多指标
- 多指标互斥时**分段**：先主战场，再把已达标项作为**拒绝式地板**做保护。
  实测：基波段做完后，第 2 段专攻二次谐波（3–5 GHz），同时把**阻带 ≤ −20 dB** 与**基波距离 ≤ 8 Ω**做成拒绝地板 ⇒ 全程未被突破。
- **单规格目标常只是把该量在带内"搬运"**（实测：低频 +0.4 dB 换来 2.2–2.3 GHz −0.4 dB）⇒ **必须给逐点增量表**，不能只给最差。

## 4. 写回（**只在整体更优时**）
1. **先备份**原单元（惯例 `<CELL>_preOpt`）；
2. **按名字路由**：把每个变量写到**真正含有它的那个 VAR 块**（早期"写第一个 VAR 实例"导致 `Expression 'OUT_W' is already defined`，hpeesofsim 拒绝展开）；
3. **只对优化集取 1 位小数**（用户硬性偏好）；其余变量**逐字节保持不变**；保留 `tune{}`/`notune{}` 注解；
4. 取整后**复核硬约束**（例：某传输线必须 >3 mm，3.05 取整成 3.0 就违规 ⇒ 取 3.1）；
5. **三处吻合验证**：① 补丁网表结果 ② 写后单元导出结果 ③ 独立复测脚本结果 —— 三者一致才收工。

## 5. 结果处置纪律
- **混合结果（某项变好、另一项变差）一律并列呈现，不擅自写回**，并把"哪个更好取决于你的口径"说清楚。
- **测量推翻了自己先前的结论时，要显式更正**（例如"阻带被卖掉"实为坏扫频造成的假象）。

## 6. 身份比对（**用户实测与我不一致时必做**）
- 对**每个候选**（不同设计变体 × 端口置换 `S11`/`S22`）× **用户给的每一点**算误差；同时报告"**无关曲线随机配对**"的误差水平（本项目 ≈ **0.45**）。
- 误差**比随机水平更差** ⇒ **形状反相关 ⇒ 是不同网络**，**不是"接近"**。
- 物理上先排除：**无源二端口的 `S11` 是固有的** ⇒ 对不上不能怪**远端端接**或**参考阻抗**。
- ⚠ 根本界限：**`S11(f)` 曲线不能唯一确定一个网络** ⇒ 要"把某匹配放进某单元"，**必需的是它的"设计"（网表/单元），不是曲线**。

## 7. 并发与命名
- **同一时刻只跑一个仿真**；诊断用的网表名/设计名/tag **必须唯一**。
- 长跑用**后台 job**；`run_code` 里的 `detached` 进程活不过该步。
- 杀进程要**按命令行匹配 PID**，杀完确认 `all clear`。
