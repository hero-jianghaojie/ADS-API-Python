# 09 项目现状与未决问题（**模板**：复制到你的项目里填写）

> 本仓库不附带任何具体项目的现状记录。下面是要点清单，按它把你的项目状态写清楚即可。

## 1. 单元清单
| 单元 | 角色 | 状态（口径 + 数值） |
|---|---|---|
| `<CELL>` | 完整功放 / 输出匹配 / 版图 / 联合仿真 testbench | <频段, 点数, Pin, FundOversample, 端接；DE/Pout/驻波> |

> **每个结论都要带口径**：频段 + 点数 + `Pin` + `FundOversample` + 器件/偏置 + 端口端接。

## 2. 可复用资产
- 评估器：`scripts/eval_*.py`
- 优化器：`scripts/pyopt_*.py`
- 出图：`scripts/plot_*.py`
- EM：`scripts/run_mom.py`、`run_em_cli.py`

## 3. 未决问题（接手第一件事就是问清）
1. 要"放进"某个单元的**网络**，其**设计（网表/单元）**在哪？（只给 `S11` 曲线不够：曲线不唯一确定网络。）
2. 判据是什么？（**宽带低 `|S11|`** 还是**进目标阻抗空间**？两者可能给出相反结论。）
3. 绝对尺度假设（如 `R_opt`）的真值是多少？
4. 某段优化结果**是否写回**？（若是混合结果：一项更好、一项更差 ⇒ 并列呈现，让用户定。）
5. 是否允许**结构改动**？（改拓扑后若走版图，**EM 必须重跑**。）
6. 是否需要把外部网络合并进现有功放链路？
